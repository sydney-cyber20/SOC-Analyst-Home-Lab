Incident Title:

Evidence Collected:


1. Windows Audit Policy
Logon auditing was enabled for Success and Failure events.

3. Failed Login Attempts

4. Windows Event Viewer Evidence

5. Multiple Failed Logons
Multiple Event ID 4625 failed logon events were detected.
Screenshot:
05-multiple-failed-logons-detected.png


6. Event 4625 Details
One failed logon event showed:

Failure Reason: Unknown user name or bad password
Computer: Windows-SOC-Lab

06-event-4625-details.png


7. Splunk SIEM Evidence
Splunk counted 10 failed logon events for soc_test.
Screenshot:
07-stats-count-by-account.png


8. Detection Logic
Splunk detection logic identified soc_test because it had 5 or more failed logons.
Screenshot:
08-brute-force-pattern-detected.png


Evidence Conclusion:
The evidence supports the finding that multiple failed logon attempts occurred against the account soc_test. This pattern may indicate brute-force activity or password guessing.
