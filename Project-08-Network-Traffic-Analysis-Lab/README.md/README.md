# Project 08: Network Traffic Analysis Lab

## Project Overview

This project demonstrates beginner network traffic analysis using Wireshark. The lab focused on capturing live network traffic on a macOS Wi-Fi interface, generating safe traffic using `ping` and `nslookup`, applying Wireshark display filters, and identifying source and destination IP addresses.

## Objective

The objective of this lab was to:

- Install and open Wireshark.
- Start packet capture on the active Wi-Fi interface.
- Generate safe DNS and ICMP traffic.
- Filter DNS traffic.
- Filter ICMP ping traffic.
- Identify source and destination IP addresses.
- Use a Wireshark IP address filter.
- Document the findings in a SOC-style analysis report.

## Tools Used

- Wireshark
- macOS Terminal
- ping command
- nslookup command
- Wi-Fi interface
- Screenshot tool
- TextEdit / Notes

## Lab Environment

The lab was performed on a Mac using Wireshark to capture traffic from the active Wi-Fi interface:

```text
Wi-Fi: en0
```

## Commands Used

The following commands were used to generate safe lab network traffic:

```bash
ping -c 4 example.com
nslookup example.com
```

| Filter | Purpose |

## Key Findings

1. Wireshark successfully captured live traffic from the Wi-Fi interface.
2. DNS traffic was observed between the local machine and the DNS server.
3. ICMP traffic was observed after running `ping`.
4. The local source IP address was identified as `192.168.1.101`.
5. The external destination IP address was identified as `104.20.23.154`.
6. Wireshark filters were used to isolate specific protocols and IP-based traffic.

## Why This Matters

Network traffic analysis is important for:

- SOC investigations
- Network troubleshooting
- Malware communication analysis
- DNS investigation
- Suspicious connection review
- Incident response
- Understanding how devices communicate over a network

SOC analysts often use packet analysis to understand what traffic was generated, which host communicated, which destination was contacted, and whether the activity appears expected or suspicious.

## Risk Level

```text
Low
```

## SOC Analyst Recommendation

Recommended actions in a real investigation:

- Review unusual destination IP addresses.
- Confirm whether contacted domains are expected.
- Check DNS queries for suspicious or malicious domains.
- Compare destination IPs and domains against known indicators of compromise.
- Investigate unexpected external communication.
- Preserve packet capture evidence when needed.
