# SOC Analyst Home Lab Portfolio

## About This Repository

This repository contains my cybersecurity home lab portfolio. The projects are focused on practical beginner skills for SOC Analyst, Junior Cybersecurity Analyst, Security Operations Support, GRC, Cloud Security, Threat Intelligence, and IT Support roles.

The portfolio demonstrates hands-on practice in vulnerability assessment, Windows security logs, Sysmon endpoint monitoring, phishing analysis, brute-force detection, Splunk SIEM analysis, user and group management, network traffic analysis, incident response reporting, GRC documentation, cloud security monitoring, and Python security automation.

## Projects

### Project 01: Vulnerability Assessment Lab

A vulnerability assessment project using Nessus to scan a lab target, identify security weaknesses, review severity levels, and document remediation recommendations.

Skills demonstrated:

- Vulnerability scanning
- Risk rating
- Remediation planning
- Security reporting

---

### Project 02: Windows Sysmon Endpoint Monitoring Lab

A Windows endpoint monitoring project using Sysmon to capture process creation and endpoint activity.

Skills demonstrated:

- Sysmon installation
- Endpoint monitoring
- Event ID review
- Process creation analysis
- Windows logging

---

### Project 03: Windows Security Event Log Analysis Lab

A Windows Security Log analysis project focused on authentication events and account activity.

Skills demonstrated:

- Windows Security Logs
- Event ID 4624 successful logon
- Event ID 4625 failed logon
- Event ID 4720 user account created
- Event ID 4672 special logon
- Authentication investigation

---

### Project 04: Phishing Email Analysis Lab

A phishing investigation project reviewing a safe sample phishing email, suspicious sender details, fake domains, suspicious URLs, and phishing indicators.

Skills demonstrated:

- Phishing analysis
- Suspicious URL review
- Email indicator identification
- Analyst note writing
- Security awareness

---

### Project 05: Brute Force Detection Lab

A brute-force detection project using Windows Security Logs to identify repeated failed login attempts against a local user account.

Skills demonstrated:

- Brute-force detection
- Event ID 4625 analysis
- Windows Event Viewer filtering
- Failed logon investigation
- SOC-style reporting

---

### Project 06: Splunk SIEM Log Analysis Lab

A SIEM analysis project using Splunk to ingest a Windows security event CSV file, search failed logons, count events by account, and identify a brute-force pattern.

Skills demonstrated:

- Splunk log ingestion
- SPL search basics
- Failed logon analysis
- SIEM investigation
- Detection logic
- Security reporting

---

### Project 07: Windows User and Group Management Lab

A Windows identity and access management project creating users, creating a security group, adding users to groups, resetting passwords, disabling accounts, and verifying status.

Skills demonstrated:

- User account creation

- Account disablement
- PowerShell verification
- Least privilege awareness

### Project 08: Network Traffic Analysis Lab

A Wireshark network analysis project demonstrating DNS traffic review, ICMP ping traffic analysis, source and destination IP identification, and display filter usage.

Skills demonstrated:

- Wireshark packet capture

- Network troubleshooting
- Packet filtering

### Project 09: Incident Response Report Lab

A SOC-style incident response project documenting a brute-force login scenario, including alert triage, incident timeline, evidence summary, containment recommendations, and a final incident response report.

A governance, risk, and compliance project showing cybersecurity risk identification, risk register creation, severity rating, recommended controls, and basic security policy documentation.
